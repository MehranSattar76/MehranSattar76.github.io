Privacy Policy for BT HID Remote: PC Mouse & Keyboard

Effective Date: November 13, 2026  |  Developer: MZ Developers (Mehran Sattar)  |  Contact: mzdevelopers001@gmail.com

🛡️ Our Core Privacy Commitment: BT HID Remote operates on a strict 100% on-device, local-hardware architecture via standard Bluetooth HID (Human Interface Device) profiles. We do NOT operate external cloud servers, we do NOT log or store keystrokes or pointer movements, and we NEVER transmit or sell your input data or personal information.

1. Overview & Architectural Principles

This Privacy Policy outlines how BT HID Remote: PC Mouse & Keyboard ("the Application", "we", "our", or "us"), package name com.mzdevelopers.bt_hid_remote, developed by MZ Developers, handles data, device permissions, and Bluetooth communications when you download and use the application on Android devices.

BT HID Remote transforms your Android smartphone or tablet into a wireless Bluetooth peripheral (touchpad mouse, keyboard, presentation clicker, media remote, and gyroscope-assisted air mouse) for paired host devices (Windows PCs, macOS, Linux, Android TV, and Raspberry Pi).

2. Zero Keystroke & Input Logging Guarantee

Your inputs and typing habits are strictly private. We adhere to non-negotiable data boundaries:

  • Volatile Memory Only: Touch coordinates, mouse clicks, keystrokes, macro payloads, and sensor readings are processed in volatile RAM purely to construct standard USB HID reports and are immediately discarded upon transmission.
  • Zero Keystroke Logging: We do NOT log, record, store, or profile keystrokes, typed text, passwords, credit card numbers, or mouse navigation history.
  • No Cloud Intermediaries: Bluetooth HID communications establish a direct peer-to-peer L2CAP channel between your phone and your host device. No telemetry servers, cloud proxies, or relay intermediaries are involved.
  • Offline Functionality: Core remote peripheral operations require zero internet connection and function in complete airplane mode once paired via Bluetooth.

3. Android Permissions & Explicit Justification

To function as a wireless hardware peripheral, the application requests specific Android operating system permissions. Each permission is strictly tied to user-facing utility:

Permission API Level Strict Purpose & Justification
BLUETOOTH_CONNECT Android 12+ (API 31+) Required to connect and transmit HID mouse and keyboard reports to previously paired host devices.
BLUETOOTH_ADVERTISE Android 12+ (API 31+) Required to register the device as a discoverable Bluetooth HID peripheral during host pairing mode.
BLUETOOTH_SCAN Android 12+ (API 31+) Used exclusively with the neverForLocation flag to discover nearby host Bluetooth devices during pairing setup.
VIBRATE All Versions Delivers tactile haptic confirmation when tapping virtual mouse buttons, trackpad gestures, and keyboard keys.
FOREGROUND_SERVICE Android 9+ (API 28+) Keeps the Bluetooth HID connection alive and responsive when switching between apps or running presentations.
FOREGROUND_SERVICE_CONNECTED_DEVICE Android 14+ (API 34+) Complies with Android 14+ requirements for apps maintaining continuous Bluetooth peripheral connections.
POST_NOTIFICATIONS Android 13+ (API 33+) Displays an ongoing status notification showing host connection state, input mute toggle, and disconnect action.

5. Anonymous Diagnostic Telemetry & Opt-Out

The Application contains an optional, privacy-safe crash reporting and diagnostic logger to identify Bluetooth stack crashes and hardware incompatibilities.

  • Pseudonymous Diagnostics: Crash logs contain only technical details (Android OS version, device model, Bluetooth chipset manufacturer, stack trace). Never personal identifiers.
  • Full User Control: You can completely disable diagnostic collection at any time under Settings → Anonymous Diagnostics.

6. Children's Privacy

BT HID Remote does not knowingly collect or solicit personal information from children under the age of 13. The application is a general-purpose hardware utility suitable for users of all ages.
